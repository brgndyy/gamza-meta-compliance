개인정보처리방침

GamzaSalada DM Automation(이하 “서비스”)은 Instagram 계정 @gamza.salada의 댓글 요청과 후속 메시지에 응답하기 위해 필요한 최소한의 정보만 처리합니다.

시행일: 2026년 8월 15일

1. 처리하는 정보

  • Instagram 댓글 ID, 게시물(미디어) ID, Instagram 범위 내 사용자 ID
  • 사용자가 보낸 메시지 또는 버튼 상호작용의 이벤트 ID와 유형
  • Webhook 이벤트 시각, 전송 성공·실패 상태와 제한된 오류 기록

댓글 본문과 DM 본문은 저장하지 않습니다. 사용자가 팔로우 확인 버튼을 누르면 Meta API로 팔로우 상태를 조회하지만 그 결과는 저장하지 않습니다.

2. 처리 목적과 수집 경로

Meta가 제공하는 공식 Instagram API와 Webhook을 통해 이벤트를 수신합니다. 관리자가 지정한 게시물 ID와 키워드가 함께 일치한 댓글만 저장하여 중복 발송 방지, 공개 답글·비공개 답장 전송, 사용자 동의 후 팔로우 상태 확인과 게시물별 정보 전달, 장애 확인에 사용합니다. 일치하는 선행 댓글이 없는 DM은 저장하지 않습니다.

3. 보관 및 삭제

자동화 처리 기록은 수집일로부터 최대 90일간 보관한 뒤 삭제합니다. 삭제 작업은 매일 실행되며 89일이 지난 기록을 제거합니다. 삭제 요청이 확인되면 법령상 보관 의무가 없는 정보는 30일 이내 삭제합니다.

4. 제공 및 처리 위탁

정보를 판매하지 않습니다. 서비스 운영을 위해 Meta Platforms와 Supabase의 인프라를 사용하며, 각 사업자의 보안 및 개인정보 보호 정책이 적용됩니다.

5. 이용자의 권리

열람·정정·삭제를 요청할 수 있습니다. 요청 방법은 데이터 삭제 안내를 확인해 주세요.

6. 보호조치

접근 권한을 제한하고, API 비밀값을 서버 측 비밀 저장소에 보관하며, Webhook 요청의 암호학적 서명과 이벤트 유효 시간을 검증합니다.

Privacy Policy

GamzaSalada DM Automation processes the Instagram comment ID, media ID, Instagram-scoped user ID, message or button-event ID and type, event time, and limited delivery/error status needed to respond to requests on @gamza.salada. Comment and DM text are not stored. Follow status is queried through Meta only when the user presses the confirmation button and is not retained.

Events are received through Meta's official Instagram API and Webhooks. Data is retained only when a configured media ID and keyword match, or when a later interaction can be linked to that matching request. Unrelated DMs are not stored. Data is not sold. A daily purge removes records older than 89 days so operational records are retained for no more than 90 days.

Infrastructure providers include Meta Platforms and Supabase. For access or deletion requests, see the Data Deletion Instructions or contact brgndyy@gmail.com.
